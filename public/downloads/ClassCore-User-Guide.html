Chapter 02

First-Time Setup & Onboarding (पहला सेटअप)

Nayi coaching ya tuition center ko setup karne ke aasan steps:

1
Installation: ClassCore-Setup-3.4.0.exe par double-click karein. Software 10 second me install hokar desktop par icon bana dega.
2
Institute Registration: App launch karke apna Name, Institute Name, Mobile Number aur Unique Username select karein.
3
Profile Setup (Settings ➔ Profile): Coaching ka Logo upload karein, Address aur Contact details bharein. Yeh details aapki sabhi Fee Receipts aur Report Cards ke top header par print hongi.
Chapter 03

Student & Batch Management (विद्यार्थी और बैच)

3.1 Student Admission

"🎓 Students" section me jakar "+ Add Student" click karein. Yahan student ka Roll Number, Name, Class, Batch aur Parent ka WhatsApp number daalein.

⚠️ Golden Rule for Roll Numbers
Student ka Roll Number numeric hona chahiye (jaise 101, 102). Yahi Roll Number student ka Biometric Machine User ID banega, jisse attendance 1-click me match ho sake!

3.2 Batch Timings & Late Calculations

"🕐 Batches" me batch create karte samay Start Time (jaise 08:00 AM) set karein. Jab koi student 15 minute baad card scan karega ya biometric punch karega, to ClassCore automatically uska status "Late" (L) mark kar dega.

3.3 Instant PVC Identity Cards

ClassCore har student ke liye barcode aur dynamic QR code wala official ID Card create karta hai. "Print All ID Cards" dabakar PVC Sheet par ek sath print karein.

Chapter 04

Attendance Ecosystem & Biometric Punch Hub

ClassCore v3.4.0 me Universal Biometric Engine diya gaya hai jo market ki kisi bhi machine aur scanner ke sath seamlessly kaam karta hai.

Category Supported Brands & Models Kaise Kaam Karta Hai?
Standalone Biometric Machines Realtime (T52, RS-10, RS-20), eSSL (MB20, K30, K20), ZKTeco, Mantra, BioMax, SecureEye Pen Drive se attlog.dat, GLog.txt ya Excel report 1-click me ClassCore me import karein.
Live USB Scanners TVS, Honeywell, Zebra, Netum, 2D QR Code Guns USB me plug karte hi auto-detect hota hai. Background me student ID card scan karte hi green card pop up hota hai.
WiFi / LAN Machines Network Biometric Terminals (Port 4370 / 5005) ClassCore IP Address ping karke machine connection test karta hai.

4.1 Pen Drive Importer Step-by-Step

1
Machine ke USB port me Pen Drive lagayein aur Menu ➔ USB Manager ➔ Download Attendance Log dabayein.
2
Pen drive computer me lagayein aur ClassCore me "⚡ Biometric & Punch Hub" me "📥 Pen Drive Importer" open karein.
3
File select karein (attlog.dat, GLog.txt ya Excel). ClassCore Roll Number se student match kar lega. "Apply Attendance" dabayein — sabhi bacchon ki attendance 1 second me lag jayegi!

4.2 Live USB Background Scanner

Scanner computer me lagate hi ClassCore chime bajata hai: "🔌 USB Scanner Connected!". Ab aap ClassCore me kisi bhi page par hon, student ka card scan karte hi top-right me Green Profile Flashcard aayega aur Present mark ho jayega. Modal khula rakhne ki zarurat nahi hai!

⚡ Background Scan Chalu / Band Switch
Attendance toolbar par aur popup modal me ek interactive switch diya gaya hai: ⚡ Background: CHALU (ON) ya ⏸️ Background: BAND (OFF). Jab aap computer par koi typing ya personal kaam kar rahe hon, to ise 1-click me BAND kar sakte hain taaki scanner ke unwanted inputs attendance me na jayein!

Cloud Sync, Backup & Recovery (डेटा सुरक्षा)

🛡️ Triple Data Safety Architecture
1. Local Drive: Sabhi records instant save hote hain.
2. Google Cloud Sync: Internet aate hi cloud backup ho jata hai.
3. Daily Auto-Snapshot: Har shaam Documents\ClassCore\Backups me encrypted backup file banti hai.

Computer badalne ya format karne par naye computer me ClassCore install karein aur "Restore from Backup" dabakar apni .ccbak file select karein. Sabhi students, fees aur marks 5 second me wapas aa jayenge!

Chapter 11

Troubleshooting & FAQs (समस्या निवारण)

Prashna / Problem Karan Samadhan (Solution)
Pen Drive me 0 punches dikh rahe hain? Machine me "New Log" select kiya tha. Machine me jayein: USB Manager ➔ Download All Log (Download ALL chunein).
Biometric punches me student name match nahi ho raha? Machine User ID aur ClassCore Roll No alag hai. Machine me student ka User ID aur ClassCore me student ka Roll No ek hi hona chahiye.
USB Scanner plug karne par chime nahi aayi? Scanner Virtual COM mode me hai ya USB port loose hai. Dusre USB port me lagayein aur scanner ke manual me se "USB HID Keyboard" barcode scan karein.
WhatsApp QR scan karne par connect nahi hota? Internet connection drop hai ya old session stuck hai. WhatsApp Hub me "Reset Session" dabayein aur fresh QR scan karein.
